# 📘 대팡 (Daepang)
> **필기 · 요약 · 퀴즈를 한 곳에서 관리하는 AI 기반 학습 통합 플랫폼**

대팡은 대학생/취업준비생이 흩어진 학습 자료를 한 곳에서 정리하고,  
AI로 퀴즈를 생성해 **복습 효율**을 높이며, 목표(자격증/시험/취업)에 맞춘 **학습 로드맵**으로 공부 흐름을 잡아주는 서비스입니다. fileciteturn1file0L1-L5

## 🧩 프로젝트 한눈에 보기
- **문제**: 자료가 많아질수록 “어디서부터/어떻게” 공부해야 할지 혼란 + 플랫폼 분산으로 학습 흐름 단절
- **해결**: 자료 통합 관리 + AI 퀴즈 + 로드맵 중심 설계로 학습을 “진행 가능한 상태”로 만듦
- **핵심 가치**: *정리 → 이해 → 퀴즈 → 복습* 흐름을 한 곳에서 완성

---

## 🎯 문제 정의 & 해결 방향

### 문제점
- 자료가 여러 곳에 흩어져 **찾는 시간**이 누적됨
- 플랫폼이 분산되어 **학습 흐름이 끊김**
- 암기 중심 공부로 **복습 효율이 낮음**

### 해결 방향
- 학습 자료를 **한 곳에서 통합 관리**
- AI가 자료를 기반으로 **퀴즈 자동 생성**
- 목표별 **로드맵 기반 학습 구조** 제공

---

## ⭐ 핵심 기능

### 1) 🤖 AI 퀴즈 생성
- 업로드/공유된 자료를 바탕으로 퀴즈를 자동 생성
- 반복 학습을 통해 핵심 개념을 점검하고 복습 루틴을 강화

### 2) 🗺️ 지식 로드맵
- 자격증/시험/목표에 맞춘 학습 단계를 시각화
- 필요한 자료/학습 순서를 한눈에 확인

### 3) 📂 자료 공유
- 필기/요약/문제 자료를 공유 및 재활용
- 공개/비공개 등 관리 방식 확장 가능
